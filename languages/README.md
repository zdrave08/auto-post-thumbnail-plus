# Translations

This folder contains translation files for Auto Post Thumbnail Plus.

## Available Translations

Currently, the plugin includes:
- `auto-post-thumbnail-plus.pot` - Template file for translations

## Contributing Translations

To translate this plugin into your language:

1. Download the `.pot` file
2. Use a translation tool like [Poedit](https://poedit.net/)
3. Create a `.po` file for your language (e.g., `auto-post-thumbnail-plus-es_ES.po` for Spanish)
4. Translate all strings
5. Generate the `.mo` file
6. Submit a pull request or contact us

## Language Codes

Common language codes:
- `de_DE` - German (Germany)
- `es_ES` - Spanish (Spain)
- `fr_FR` - French (France)
- `it_IT` - Italian (Italy)
- `pt_BR` - Portuguese (Brazil)
- `ru_RU` - Russian
- `zh_CN` - Chinese (Simplified)
- `ja` - Japanese
- `sr_RS` - Serbian

## WordPress.org GlotPress

Once the plugin is on WordPress.org, translations can be contributed through:
https://translate.wordpress.org/projects/wp-plugins/auto-post-thumbnail-plus/

## Notes

- The `.pot` file is automatically updated when new translatable strings are added
- WordPress will automatically load translation files from this folder
- File naming convention: `auto-post-thumbnail-plus-{locale}.mo`
